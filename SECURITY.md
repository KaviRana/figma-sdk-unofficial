# Security Policy

## Reporting a vulnerability

Please report security issues privately to Kavita.

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/KaviRana/figma-sdk-unofficial/issues

## Scope

This policy applies to the generated Kavita SDK packages published from this
repository (npm, PyPI, Packagist, RubyGems, LuaRocks, and the Go module).

This is an unofficial SDK for the Figma public API, generated by
Kavita. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
